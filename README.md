Stunts
======

A TypeScript / WebGL implementation of the classic DOS stunt-driving game.

## Features

- **11 original cars** — Corvette, Countach, Ferrari GT, Jaguar, Lancia, Porsche variants, Audi Quattro
- **Stunts-style physics** — engine torque curves, gearing, suspension, weight transfer, surface grip
- **Track editor** — DOS-style icon palette (F1–F7), paint while driving, save/load `.TRK`
- **Original-style music** — procedural AdLib-inspired soundtrack (toggle with M)
- **Classic track rendering** — original OBJ tile library and binary `.TRK` format
- **Horizon backgrounds** — alpine, tropical, desert, city, country themes

## Getting Started

```bash
pnpm install
pnpm dev
```

Open http://localhost:5173

## Controls

### Driving

| Key | Action |
|-----|--------|
| W / ↑ | Throttle |
| S / ↓ | Brake / reverse |
| A / ← | Steer left |
| D / → | Steer right |
| Q / Z | Next / previous car |
| R | Reset to start |
| C | Toggle chase / hood camera |
| E | Enter track editor |
| M | Toggle music |
| F1–F7 | Editor tile categories |
| T | Top-down camera (in editor) |

### Track Editor

| Action | Description |
|--------|-------------|
| Click / drag | Paint tiles (full 3D OBJ models appear instantly) |
| F1–F7 | Switch category (Basic, Road, Stunts, Banks, Structures, Scenery, Terrain) |
| Save .TRK | Download track file |
| Load .TRK | Import a track file |
| New Track | Start with a blank layout |

Tile palette icons are 32×32 VGA-style images in `public/texs/editor/tiles/`. Regenerate with `pnpm generate:icons`.

## Test

Automated verification:

```bash
pnpm test              # unit + browser + visual (12 overhead map screenshots)
pnpm test:unit         # assets and track I/O only
pnpm test:browser      # headless Chrome smoke test
pnpm test:visual       # compare 12 overhead map renders to baselines
pnpm test:visual:update  # regenerate visual baselines after intentional changes
```

### Visual map tests

Twelve test tracks in `trks/test/` are rendered from an **orthographic overhead camera** (640×480) and compared to baseline PNGs in `tests/visual/baselines/` using pixelmatch.

| Map | Features tested |
|-----|-----------------|
| default | Closed road loop |
| oval | Larger oval circuit |
| straight | Long drag strip |
| ramps | Four-direction ramps |
| loops | Loop-the-loop tiles |
| pipes | Pipe / half-pipe |
| banks | Banked turns |
| bridge | Bridge sections |
| scenery | Palm, tree, barn, gas |
| hills | Terrain slopes and plateaus |
| stadium | Stadium corners |
| stunt-mix | Corkscrew, espresso, slalom |

Regenerate test tracks: `pnpm generate:tracks`

## Car Models

Car OBJ meshes live in `objs/car/` and are generated by:

```bash
pnpm generate:cars
```

These are stylized placeholders at original Stunts scale. Replace with meshes exported from the DOS game via [stressed](https://github.com/dstien/stressed) for authentic visuals.

## Project Layout

```
src/
  car/        Car definitions, model loader, vehicle class
  physics/    Stunts-style simulation engine
  track/      TRK parser/serializer, tile placement, model loading
  editor/     Track editor UI and palette
  audio/      Procedural Stunts-inspired music
  game/       Game loop, input, rendering
objs/trk/     Classic track tile OBJ models
objs/car/     Car OBJ models
trks/         Track files (.TRK)
texs/         Horizon backdrop images
```
